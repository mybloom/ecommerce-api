# 공통 컨벤션

> 큐레이션 오픈마켓 도메인 전반에 적용되는 공통 규칙. 특정 애그리거트가 아닌 시스템 전체에 적용된다.

> **원칙**: 이 문서의 규칙은 모든 도메인 문서와 코드에 일관되게 적용된다. 예외가 필요한 경우 결정 이력에 명시한다.

---

## 1. 시간 컨벤션

### 1.1. 명명 정책

모든 엔티티는 `BaseEntity`로부터 `createdAt`을 자동 상속한다 (인프라 표준). 이는 "이 레코드가 DB에 저장된 시각"을 나타내는 기술적 메타데이터이다.

도메인 의미가 별도로 필요한 경우 `likedAt`, `openedAt` 같은 도메인 언어 필드를 **추가로** 둔다. 이 필드들은 `createdAt`을 대체하지 않으며, 도메인 사건의 발생 시점을 명시적으로 표현하기 위해 함께 존재한다.

| 분류 | 예시 | 의미 |
|---|---|---|
| 인프라 표준 (자동) | `createdAt` | 레코드가 저장된 시각. BaseEntity로부터 모든 엔티티가 보유 |
| 도메인 언어 (선택적 추가) | `likedAt`, `openedAt` | 도메인 사건의 발생 시점. 일반적으로 `createdAt`과 같지만 의미가 다름 |

### 1.2. 도메인 언어 필드를 추가하는 기준

다음 중 하나에 해당할 때 도메인 언어 필드를 별도로 둔다.

- 사용자에게 그 시점을 노출해야 함 (예: "좋아요 누른 시각" 표시)
- `createdAt`과 다른 시점이 될 가능성이 있음 (예: 일괄 임포트, 백필)
- 도메인 사건의 의미를 코드/응답에서 명확히 표현하고 싶음

해당 사항이 없으면 `createdAt`만 사용한다.

### 1.3. 시간 타입

| 타입 | 의미 | 사용처 |
|---|---|---|
| ZonedDateTime | 시간대 정보를 가진 날짜+시간 | `Member.createdAt`, `MemberProfile.createdAt`, `Product.openedAt`, `ProductLike.likedAt` |
| LocalDate | 날짜만 표현 (시간 정보 없음) | `Member.birthDate`, `MemberProfile.birthDate` |

### 1.4. 현재 도메인의 시간 필드

| 필드 | 종류 | 의미 |
|---|---|---|
| `Member.createdAt` | 인프라 표준 | 회원 레코드가 저장된 시각 (= 회원가입 시각) |
| `Product.openedAt` | 도메인 언어 | 상품 개시 일시. `createdAt`과 별개로 명시적 도메인 의미 보유 |
| `ProductLike.likedAt` | 도메인 언어 | 좋아요를 누른 시각. UC-3 정렬과 출력에 사용됨 |
| `Member.birthDate` | 도메인 (날짜) | 회원의 생년월일 |

> Product와 ProductLike는 도메인 언어 필드(`openedAt`, `likedAt`)를 두면서도 BaseEntity의 `createdAt`은 그대로 보유한다. 두 시점은 보통 같지만, 의미가 다르므로 별도 컬럼으로 존재한다.

## 2. 향후 추가될 컨벤션

본 문서는 시간 컨벤션을 시작으로 점차 확장될 예정이다. 추가 후보:

- [ ] 식별자 컨벤션 (Long vs UUID, 도메인별 ID 타입 정책)
- [ ] 명명 컨벤션 (메서드명, 클래스명, 패키지 구조)
- [ ] 예외 처리 컨벤션 (`CoreException`, `ErrorType` 사용 정책)
- [ ] 값 객체 작성 컨벤션 (정적 팩토리 `of`, 검증 위치 등)
- [ ] 영속화 컨벤션 (BaseEntity 구조, 컬럼 매핑 정책)
