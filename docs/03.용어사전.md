# e상점 용어 사전

| **한국어** | **영어**         | **설명**                                     |
|---------|----------------|--------------------------------------------|
| 회원      | Member         | 서비스를 이용하는 사용자로 물건을 구매할 수 있다                |
| 회원 정보   | Member Profile | 회원의 ID, 성별, 생년월일, 이메일 주소등 조회 가능한 회원의 기본 정보 |
| 포인트     | Point          | 사전 충전된 포인트로 상품을 결제한다.                      |
