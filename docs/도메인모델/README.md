# 도메인 모델 명세

애그리거트별 **행위 · 구조 · 설계 결정**을 기록한 문서입니다.

- **A. 행위** — 유스케이스별 입력 · 처리 · 결과와 실패 조건
- **B. 구조** — 엔티티 · 값 객체 · 상태 전이
- **C. 설계 결정** — `Order-004` 처럼 번호를 붙인 판단과 근거
---

## 애그리거트

| # | 문서 | 애그리거트 | 결정 | 핵심 결정 |
|---|---|---|---|---|
| 01 | [Member](./01_member.md) | `Member` | 2 | 비밀번호는 해시로만 보관하고, 외부 노출은 `MemberProfile` 로만 |
| 02 | [Point](./02_point.md) | `Point` | 4 | 회원당 하나. 가입 시 함께 생성하고 잔액은 `Money` 가 지킴 |
| 03 | [Brand](./03_brand.md) | `Brand` | 1 | 비활성 브랜드의 상품은 노출하지 않음 |
| 04 | [Product](./04_product.md) | `Product` | 3 | 좋아요 수는 캐시 컬럼. `decreaseLikeCount()` 는 0에서 멈춤 |
| 05 | [ProductLike](./05_product-like.md) | `ProductLike` | 9 | 중복 좋아요·부재 취소는 멱등. UNIQUE 위반을 멱등 성공으로 변환 |
| 06 | [Order](./06_order.md) | `Order` | 11 | 접수와 확정을 두 트랜잭션으로. 재고 경합은 비관적 락 |
| 07 | [Payment](./07_payment.md) | `Payment` | 7 | 별도 애그리거트 루트. 주문을 종결시키는 것은 결제 |
