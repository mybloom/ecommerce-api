# Brand 애그리거트

> **범위**: 큐레이션 오픈마켓 MVP — 사용자 관점

---

## A. 행위

> **책임**: 상품을 제공하는 브랜드의 정보를 표현한다. 사용자가 브랜드 단위로 상품을 필터링하거나 식별할 때의 기준이 되며, 브랜드 자체에 대한 정보를 사용자에게 제공한다.

### UC-1. 브랜드 정보 조회

**목적**  
사용자가 특정 브랜드의 정보(이름, 설명 등)를 확인한다. 보통 상품 목록이나 상세에서 브랜드명을 클릭했을 때 진입한다.

**입력**

- `brandId` : BrandId — 조회할 브랜드 식별자

**출력**

브랜드 정보:
- 브랜드 ID
- 브랜드명
- 브랜드 설명

**필터 정책**
- `status == ACTIVE`인 브랜드만 조회 가능
- `INACTIVE`, `WITHDRAWN` 상태의 브랜드 조회 시 "찾을 수 없음" 응답

### 도메인 이벤트

> 현재 단계에서는 이벤트 도입 보류.

## B. 구조

> 위 행위를 가능하게 하는 내부 구성. 애그리거트 루트와 값 객체, 외부 관계로 이루어진다.

### B.1. Brand : Entity, Aggregate Root

#### 속성

- `id` : Long — 식별자
- `name` : String — 브랜드명
- `description` : String — 브랜드 설명
- `status` : BrandStatus — 브랜드 상태

#### 행위

- `isVisibleToUser()` : Boolean — 사용자에게 노출 가능한 상태인지 반환한다. `ACTIVE`만 `true`

> 그 외 행위(브랜드 등록, 정보 변경, 상태 변경 등)는 해당 유스케이스가 정의될 때 함께 추가한다.

---

### B.2. BrandStatus : Value Object

브랜드 상태를 나타내는 열거형.

#### 속성

- `ACTIVE` — 활성 (사용자에게 노출됨, 상품 노출 가능)
- `INACTIVE` — 비활성 (노출되지 않음, 운영상 사유로 일시 정지)
- `WITHDRAWN` — 탈퇴 (영구 종료, 노출되지 않음)

---

### B.3. 다른 애그리거트와의 관계

- **Product** → `Product`가 `brandId`로 이 애그리거트를 참조함
    - 상품 목록 조회 시 브랜드 필터로 사용 (참고: Product.md UC-1)
    - 상품 요약에 브랜드명 표시 (Product 조회 결과와 조합)
    - 브랜드가 `ACTIVE`가 아닐 때 해당 브랜드 상품은 노출되지 않음 (참고: Brand-001)

## C. 설계 결정

> 확정된 결정과 보류된 결정을 함께 모은다. 보류된 항목이 결정되면 C.2 → C.1로 이동한다.

### C.1. 확정된 결정

> **왜 이런 선택을 했는지** 보존한다. 결정은 누적될 뿐 수정되지 않는다.

#### Brand-001. 비활성 브랜드의 상품은 노출하지 않음
- **일시**: 2026-05-07
- **결정**: Brand의 상태가 `ACTIVE`가 아닌 경우(`INACTIVE`, `WITHDRAWN`), 해당 브랜드에 속한 상품은 사용자 화면에서 노출하지 않는다.
- **이유**:
    - 브랜드가 비활성/탈퇴한 상태인데 상품만 보이면 사용자 혼란
    - "이 브랜드의 다른 상품 보기" 같은 회유 동선이 깨짐
    - 비활성 브랜드의 상품을 수동으로 모두 숨기는 운영 부담 회피
- **영향**:
    - 상품 목록 조회(Product UC-1) 시 Brand의 상태를 함께 확인해야 함
    - 단순 `Product.status == ON_SALE` 조건으로는 부족, Brand 조인 또는 추가 조회 필요
- **관련 애그리거트**: Product (참고: Product.md UC-1)
- **재검토 시점**: 브랜드 상태와 상품 노출이 독립적으로 관리되어야 하는 요구사항이 생길 때 (예: 브랜드 휴면 중에도 일부 상품은 판매 계속).

### C.2. 보류된 결정

> 아직 결정되지 않았거나 **앞으로 다룰 항목**을 모은다. 결정되면 C.1로 이동한다.

- [ ] 브랜드 로고 이미지 속성 추가
- [ ] 브랜드관 페이지 (브랜드별 상품 목록 + 브랜드 소개)
- [ ] 입점 판매자(Seller) / 공급사(Supplier) 개념과의 관계 정립
- [ ] 브랜드 등록/정보 변경/상태 변경 유스케이스 정의 (관리자 영역)
- [ ] 도메인 이벤트 도입
