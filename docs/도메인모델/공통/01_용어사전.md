# 용어사전

> 큐레이션 오픈마켓 MVP의 도메인 용어를 모은 사전. 각 용어의 상세 정의는 해당 도메인 문서에 있으며, 본 사전은 빠른 참조와 한국어↔영어 매핑을 위한 인덱스 역할을 한다.

> **원칙**: 본 사전은 정의의 원본이 아니라 **인덱스**이다. 상세 정의가 충돌하면 각 애그리거트 문서가 우선한다.

---

## 1. 애그리거트와 엔티티

| 한국어 | 영어 | 정의 | 출처 |
|---|---|---|---|
| 회원 | Member | 시스템을 사용하는 사용자. 회원가입을 통해 등록되며, 다른 도메인에서 행위의 주체로 참조됨 | [Member](../01_member.md) |
| 회원 프로필 | MemberProfile | 회원 정보를 외부에 노출할 때 사용하는 안전한 표현. `passwordHash` 등 민감 정보 제외 | [Member](../01_member.md) |
| 포인트 | Point | 회원이 보유한 포인트 잔액. 회원가입 시 잔액 0으로 함께 생성됨 | [Point](../02_point.md) |
| 상품 | Product | 사용자가 탐색하고 구매하는 단위. 브랜드에 소속되며 좋아요의 대상 | [Product](../04_product.md) |
| 브랜드 | Brand | 상품을 제공하는 주체. 사용자가 브랜드 단위로 상품을 필터링하거나 식별 | [Brand](../03_brand.md) |
| 좋아요 | ProductLike | 사용자가 상품에 표현한 관심의 기록. 정렬과 위시리스트의 근거 | [ProductLike](../05_product-like.md) |
| 주문 | Order | 회원이 상품과 수량을 지정해 접수한 구매 요청. 확정되면 라인과 총액이 고정됨 | [Order](../06_order.md) |
| 주문 라인 | OrderLine | 주문에 담긴 상품 한 종류. Order 애그리거트 내부이며 단독으로 존재하지 않음 | [Order](../06_order.md) |
| 결제 | Payment | 확정된 주문의 금액을 받아낸 기록. 주문과 1:1이며 별도 애그리거트 루트 | [Payment](../07_payment.md) |

## 2. 값 객체

### 2.1. 도메인 값 객체

| 한국어 | 영어 | 정의 | 출처 |
|---|---|---|---|
| 이메일 | Email | 이메일 주소를 표현. 형식 검증 포함 | [Member](../01_member.md) |
| 성별 | Gender | 회원의 성별. `MALE`, `FEMALE` | [Member](../01_member.md) |
| 금액 | Money | 통화 금액을 표현. 음수 불가, 산술 연산 안전성 보장. 시스템 전역 공유 | [Point](../02_point.md) |
| 재고 수량 | StockQuantity | 상품의 재고를 표현. 0 이상 정수 | [Product](../04_product.md) |
| 주문번호 | OrderNumber | 사용자에게 노출하는 주문 식별자. `yyyyMMdd-{8자리 영숫자}` 형식 | [Order](../06_order.md) |
| 중복 요청 식별자 | IdempotencyKey | 같은 주문 요청을 한 번만 처리하기 위해 클라이언트가 발급하는 키 | [Order](../06_order.md) |


### 2.2. 상태 열거형

| 한국어 | 영어 | 값 | 출처 |
|---|---|---|---|
| 상품 판매 상태 | ProductStatus | `ON_SALE`, `OFF_SALE`, `HIDDEN` | [Product](../04_product.md) |
| 브랜드 상태 | BrandStatus | `ACTIVE`, `INACTIVE`, `WITHDRAWN` | [Brand](../03_brand.md) |
| 정렬 기준 | ProductSort | `latest`, `priceDesc`, `likeDesc` | [Product](../04_product.md) |
| 주문 상태 | OrderStatus | `PENDING`, `AWAITING_PAYMENT`, `ORDER_FAILED`, `PAID`, `PAYMENT_FAILED` | [Order](../06_order.md) |
| 결제 수단 | PaymentMethod | `POINT`, `CARD` | [Payment](../07_payment.md) |
| 결제 상태 | PaymentStatus | `PENDING`, `APPROVED`, `FAILED` | [Payment](../07_payment.md) |

## 3. 핵심 도메인 행위

같은 도메인 사건을 가리키는 한국어 표현과 코드의 영어 메서드명을 매핑한다.

| 한국어 | 영어 | 의미 | 출처 |
|---|---|---|---|
| 회원가입 | register | 새 회원이 시스템에 등록되는 행위 | [Member](../01_member.md) |
| 비밀번호 검증 | verifyPassword | 평문 비밀번호가 저장된 해시와 일치하는지 확인 | [Member](../01_member.md) |
| 프로필 추출 | toProfile | Member에서 외부 노출용 MemberProfile을 만드는 행위 | [Member](../01_member.md) |
| 좋아요 누르기 | like | 사용자가 상품에 좋아요를 새로 등록 | [ProductLike](../05_product-like.md) |
| 좋아요 취소 | unlike | 등록된 좋아요를 제거 | [ProductLike](../05_product-like.md) |
| 포인트 충전 | charge | 포인트 잔액을 증가시킴 | [Point](../02_point.md) |
| 포인트 사용 | use | 포인트 잔액을 차감함. 포인트 결제 요청 안에서 호출됨 | [Payment](../07_payment.md) |
| 초기 포인트 생성 | createInitial | 잔액 0의 Point 인스턴스를 생성 | [Point](../02_point.md) |
| 주문 접수 | draft | 멱등키까지 확인해 주문을 `PENDING`으로 기록 | [Order](../06_order.md) |
| 주문 확정 | confirm | 라인과 총액을 고정하고 `AWAITING_PAYMENT`로 전이 | [Order](../06_order.md) |
| 주문 실패 처리 | markOrderFailed | 검증·재고 확보 실패를 `ORDER_FAILED`로 기록 | [Order](../06_order.md) |
| 결제 완료 처리 | pay | 주문을 `PAID`로 전이하고 결제 시각을 기록 | [Order](../06_order.md) |
| 결제 실패 처리 | markPaymentFailed | 주문을 `PAYMENT_FAILED`로 전이 | [Order](../06_order.md) |
| 상태 전이 검사 | requireTransitionTo | 허용되지 않은 상태 전이면 `CONFLICT` 예외를 던짐 | [Order](../06_order.md) |
| 재고 차감 | decreaseStock | 주문 확정 시 상품 재고를 주문 수량만큼 뺌 | [Order](../06_order.md) |
| 재고 복원 | increaseStock | 결제 실패 시 확보했던 재고를 주문 수량만큼 되돌림 | [Payment](../07_payment.md) |
| 결제 요청 | request | 결제를 접수해 `PENDING` Payment를 만듦 | [Payment](../07_payment.md) |
| 결제 승인 | approve | 결제를 `APPROVED`로 확정하고 승인 시각을 기록 | [Payment](../07_payment.md) |
| 결제 실패 확정 | fail | 결제를 `FAILED`로 확정하고 실패 사유를 남김 | [Payment](../07_payment.md) |

## 4. 도메인 정책 용어

| 한국어 | 영어 | 정의 | 출처 |
|---|---|---|---|
| 품절 | SoldOut | 상품의 재고 수량이 0인 상태. `Product.isSoldOut`으로 판단 | [Product](../04_product.md) |
| 활성 (브랜드) | Active | 브랜드가 정상 노출되는 상태. `BrandStatus.ACTIVE` | [Brand](../03_brand.md) |
| 비활성 (브랜드) | Inactive | 운영상 사유로 일시 차단된 브랜드. 해당 브랜드 상품은 노출 제외 | [Brand](../03_brand.md) |
| 탈퇴 (브랜드) | Withdrawn | 영구 종료된 브랜드 | [Brand](../03_brand.md) |
| 멱등 처리 | Idempotent handling | 동일 요청이 반복되어도 같은 결과를 보장. 좋아요 중복/부재 처리, 주문 접수, PG 콜백 수신에 적용 | [ProductLike](../05_product-like.md) |
| 스냅샷 | Snapshot | 주문 시점의 상품명·단가를 복사해 보관하는 것. 이후 상품이 바뀌어도 주문 내용은 고정 | [Order](../06_order.md) |
| 결제 대기 | AwaitingPayment | 재고를 확보하고 결제를 기다리는 주문 상태. 이 구간 동안 재고가 묶임 | [Order](../06_order.md) |
| 주문 실패 | OrderFailed | 접수 후 검증·재고 확보에 실패한 상태. 재고가 확보된 적이 없어 되돌릴 것이 없음 | [Order](../06_order.md) |
| 결제 실패 | PaymentFailed | 결제에 실패해 **확보했던 재고가 복원된** 상태. 주문 실패와 재고 상태가 다름 | [Order](../06_order.md) |
| 보상 | Compensation | 트랜잭션 롤백으로 되돌릴 수 없는 것을 명시적으로 되돌리는 처리. 결제 실패 시의 재고 복원 | [Payment](../07_payment.md) |
