

# 도메인 모델 산출 방법

이번 태스크는 REST API 명세가 주어진 상황에서 요구사항을 도출해서 도메인 모델을 산출하는 것이다.

1. "e-상점 도메인" 설명 작성 근거
    - API 명세로부터 필요한 요구사항과 규칙을 나열한다.
2. 개념을 용어로 뽑아낸다.
    - 이해한 내용에서 핵심적인 것들을 뽑아내는 작업
    - 도메인 모델은 이 도메인이 가지고 있는 문제에 대한 추상화되고 간략화된 지식 또는 그런 개념들의 집합
    - 처음 한번 만들고 끝나는 게 아니고 코드와 함께 계속 같이 업데이트 되어야 함.
    - 예시) 제일 눈에 띄는 것 뽑아보기 → 핵심적인 것
        - 회원 
3. 용어 사전 만들기 -> "용어사전.md"
    - 위 과정에서 뽑아낸 핵심 단어에 대한 `영어단어`, `정확한 정의` 설명
4. 애그리거트 만들기
    - 뽑은 용어에서 엔티티, Enum, Vo 구분
    - 각 속성, 행위, 규칙을 작성한다.
    - 생성과 관련된 행위는 static 메서드로 작성
